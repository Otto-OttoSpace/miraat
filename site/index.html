AI writes most of your UI now — and it's quietly bad at العربية / RTL.

It reaches for ml-4, text-left, hard-codes dir="ltr", never mirrors an icon. Looks fine in English. Breaks the second an Arabic, Hebrew, Syriac, Thaana, N’Ko or Adlam user opens it. Miraat (formerly rtlint) finds it, fixes what's mechanical, and flags what needs a human.

$ npx miraat . --fix

Before → after

- <div dir="ltr" className="ml-4 pr-2 text-left border-l rounded-l-lg">
- margin-left:16px; padding-right:8px; text-align:left;
+ <div dir="ltr" className="ms-4 pe-2 text-start border-s rounded-s-lg">
+ margin-inline-start:16px; padding-inline-end:8px; text-align:start;

Physical direction (left/right) → logical (start/end), which flips automatically with the document. One idea kills ~80% of RTL bugs — and --fix just does it.

What it catches

  • AUTO-FIX
    Physical CSS → logical properties
  • AUTO-FIX
    Physical Tailwind → ms/me/ps/pe/start/end
  • FLAG
    Hard-coded dir="ltr"
  • FLAG
    Un-mirrored directional icons
  • FLAG
    Script-blind fonts (no RTL-capable fallback)
  • FLAG
    Locale-blind numerals / dates / bidi

Physical→logical, dir and mirrored-icon flags fire for every RTL script — Arabic, Hebrew, Syriac, Thaana, N’Ko, Adlam. The half that makes each one actually feel right — icons, type, bidi, culture — takes native judgment. Miraat flags those; it doesn't guess. That judgment is the Pro audit.
