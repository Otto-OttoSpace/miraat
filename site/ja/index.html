AIが書く右書き（RTL）のバグを捕まえる。

Miraat は React / Next / Tailwind のリポジトリをスキャンし、AIコード生成が標準で埋め込むRTLのバグ — 物理CSS、反転すべきアイコン、崩れた bidi — を、あらゆる右書きスクリプトにわたって自動修正します。

GitHub ↗ npx github:Otto-OttoSpace/miraat
01 機能

AST検証つき自動修正

確信度の高い修正だけを適用。曖昧なものはすべてフラグを立て、黙って変更することはありません。

あらゆるRTLスクリプト

アラビア語、ヘブライ語、シリア語、ターナ文字、ンコ文字、アドラム文字 — アラビア語だけではありません。

エージェント・ネイティブ

MCP サーバーと Claude Skill を同梱。AIツールがバグを再び持ち込むのを止めます。

CI対応

GitHub Action とバイト単位で正確な回帰コーパス。破損ゼロを保証します。
